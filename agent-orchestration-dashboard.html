Claude Code / マルチエージェント開発

Claude Agent Roster

誰(エージェント)に何(タスク)をさせるかをここで決め、Claude Code のエージェントチーム定義や Paperclip の組織図としてそのまま書き出せる配役ボードです。

エージェント (誰が)

役割・モデル・使えるツール・担当範囲を編集。リードは1人固定。

タスク (何を)

担当を選ぶとエージェント側の負荷バーに反映されます。

委任の流れ

リード → 担当 → レビュー担当 の順にタスクが渡る想定図。

書き出し (どう動かすか)

設定をそのまま各OSSに持ち込める形式で生成します。

用途別のおすすめ

  

    

      
役割・権限・予算まで GUI で細かく決めたい

      
Paperclip。組織図で「誰が誰に報告し、何をしてよいか」を定義でき、Claude Code を含む複数 CLI を混在させられる。このページの「Paperclip 組織図 JSON」タブが下書きになる。

    

    

      
追加ツール無しで Claude Code だけで始めたい

      
Agent Teams + サブエージェント定義。役割は .claude/agents/ の Markdown に書くだけ。GUI は無いが、このページの「.claude/agents/*.md」タブの出力をそのまま置けば動く。

    

    

      
PR 単位で並列に回して merge まで見たい

      
Orchestrator.inc。Kanban でワーカーの状態が一目で分かり、CI 失敗やレビューコメントが担当ワーカーへ自動で戻る。役割の自由度は低め。

    

    

      
tmux で軽量に、役割は自由に

      
orch。Go バイナリ1本。--role に好きな役割名、--spec に指示書を渡す方式で、このページの「orch コマンド」タブがそのまま使える。

    

  

  
スター数や「サンセット」等の状態は検索時点の各リポジトリ/記事の表示を転記したもので、導入前に本家リポジトリで再確認してください。配役ボードの編集内容はこのブラウザの localStorage にのみ保存されます。
