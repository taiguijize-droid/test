# HIG 検証チェックリスト

各項目に ✅ / ❌ / N/A を付け、❌ には場所 (ファイル:行 または 画面名) を添える。
Web は `scripts/hig-audit.mjs` が A・B・C・E の一部を自動で出す。残りは目視。

## A. 文字

- [ ] 本文は 17px、最小 11px (iOS) / 13px・10px (macOS) を下回っていない
- [ ] font-weight 400 未満を使っていない
- [ ] 使用書体は 2 系統以内
- [ ] 見出し → 本文 → 補足 の階層がサイズ・ウェイト・色で読める
- [ ] 文字を 200% に拡大 (ブラウザのズーム 200% または Dynamic Type AX5) しても切れ・重なりがない
- [ ] 拡大時に横並びが縦積みになる、行高が伸びる

## B. 操作要素

- [ ] すべての操作要素が 44×44px 以上 (macOS は 28×28)
- [ ] 隣接する操作要素の間に 8px 以上 (推奨 12px) の余白
- [ ] 主要アクションは画面の読み順で早い位置、または標準位置 (ナビバー右上など)
- [ ] 破壊的操作は赤で、かつ確認または取り消し手段がある
- [ ] スワイプなどジェスチャ操作に対応するボタンがある

## C. 色

- [ ] 17px 以下の文字と背景のコントラスト 4.5:1 以上、18px 以上 / Bold は 3:1 以上
- [ ] ライトとダーク両方で上記を満たす
- [ ] 色だけで状態・エラー・選択を伝えていない (アイコン / 形 / 文言がある)
- [ ] 同じ色に複数の意味を持たせていない
- [ ] アクセント色は主要アクション 1 つに限定。ツールバーのボタン全部に色を付けていない
- [ ] セマンティック名 (label / secondary / separator / background) でトークン化されている

## D. レイアウト

- [ ] セーフエリア (`env(safe-area-inset-*)`) を尊重
- [ ] 375px 幅で横スクロールが出ない。レイアウトはサイズクラス (幅) で決めている
- [ ] 関連要素がグループ化され、整列している
- [ ] 初期表示に不要な情報が段階的開示に隠れている
- [ ] 背景がツールバー・タブバー・サイドバーの下まで延びている

## E. マテリアルとモーション

- [ ] Liquid Glass 風の効果はコントロール層だけ。カード・コンテンツに使っていない
- [ ] 透過の上の文字が読める (必要なら減光層)
- [ ] `prefers-reduced-motion: reduce` で移動・拡大のアニメーションがフェードまたは無効になる
- [ ] 自動で消える通知・UI に依存していない
- [ ] 自動再生メディアに停止手段がある

## F. アクセシビリティ

- [ ] すべてのボタン・リンク・入力にアクセシブル名 (テキスト / aria-label / label)
- [ ] 画像に alt (装飾は alt="")
- [ ] キーボードで全操作でき、フォーカスリングが見える
- [ ] フォーカス順が視覚順と一致
- [ ] フォーム入力に可視ラベル。プレースホルダだけに頼らない
- [ ] エラーは何が起きたか・どう直すかを文章で伝える

## G. 原則との整合 (一行ずつ答える)

- Agency: 戻る / やり直す手段は ___
- Familiarity: 使った標準パターンは ___
- Simplicity: 削った要素は ___
- Delight: 狙った感情は ___
